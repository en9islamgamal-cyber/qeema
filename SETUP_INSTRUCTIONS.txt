🔴 ملف مهم جداً — اقرأه أولاً!
═══════════════════════════════════════════════════════

قبل ما تشغّل الـ Pipeline لأول مرة، لازم تعمل Setup في Supabase:

═══════════════════════════════════════════════════════
خطوة 1: روح Supabase Project
═══════════════════════════════════════════════════════

1. روح: https://supabase.com
2. اختر project بتاعك
3. اضغط على "SQL Editor" (من القائمة اليسارية)

═══════════════════════════════════════════════════════
خطوة 2: افتح ملف supabase_schema.sql
═══════════════════════════════════════════════════════

افتح الملف `supabase_schema.sql` من الريبو
(موجود في root directory)

═══════════════════════════════════════════════════════
خطوة 3: انسخ وليصق في SQL Editor
═══════════════════════════════════════════════════════

1. انسخ كل محتوى supabase_schema.sql
2. في Supabase SQL Editor، اضغط "New Query"
3. ليصق المحتوى
4. اضغط "Run" (الزرار الأزرق)

═══════════════════════════════════════════════════════
خطوة 4: تحقق من النتيجة
═══════════════════════════════════════════════════════

✅ يجب تشوف:
   - جدول "episodes" تم إنشاؤه
   - 20 حلقة مضافة بـ status='pending'
   - رسالة نجاح

❌ لو في خطأ:
   - اقرأ الرسالة
   - تأكد أنك نسخت الملف كامل
   - جرّب تاني

═══════════════════════════════════════════════════════
خطوة 5: بعدين شغّل Pipeline
═══════════════════════════════════════════════════════

1. روح GitHub → Actions
2. اختر "VALUE QEEMA Pipeline"
3. اضغط "Run workflow"
4. ليصق:
   - episode_number: (فارغ)
   - dry_run: ✅ checked (للاختبار الأول)
   - اضغط "Run workflow"

═══════════════════════════════════════════════════════
خطوة 6: راقب الـ Logs
═══════════════════════════════════════════════════════

1. انتظر الـ workflow ينتهي (5-10 دقائق)
2. اضغط على "Produce Episode" job
3. اشوف الـ logs — يجب تشوف:

✅ إذا نجح:
   "✅ جميع المحركات جاهزة"
   "✅ تم توليد الحلقة"

❌ إذا فشل:
   اقرأ الـ error message

═══════════════════════════════════════════════════════
مشاكل شائعة والحل:
═══════════════════════════════════════════════════════

❌ "Could not find the table 'episodes'"
✅ الحل: نسيت تشغّل supabase_schema.sql
   → روح Supabase SQL Editor وشغّل الـ schema

❌ "Missing: GEMINI_API_KEY"
✅ الحل: نسيت تضيف الـ secrets في GitHub
   → Settings → Secrets → أضف كل الـ 9 secrets

❌ "Connection refused"
✅ الحل: جرّب تاني — قد تكون خدمة مشغولة
   → استنى دقيقة وجرّب تاني

❌ "HTTP 404"
✅ الحل: تحقق أن SUPABASE_URL و SUPABASE_KEY صح
   → روح Supabase Dashboard → Settings → API

═══════════════════════════════════════════════════════
معلومات سريعة:
═══════════════════════════════════════════════════════

▪ الـ Cron: الاثنين والخميس الساعة 6 صباحاً (تلقائي)
▪ Timeout: 180 دقيقة (3 ساعات)
▪ Artifacts: حفظ 21 يوم
▪ DRY_RUN: للاختبار بدون رفع يوتيوب

═══════════════════════════════════════════════════════

أي مشكلة؟ اضغط "Explain error" في GitHub Actions 🚀
