# 🌙 VALUE / QEEMA — خط الإنتاج القرآني

**إصدار 2.0 — الاحترافية القصوى**

مشروع أتمتة كامل لإنتاج محتوى تعليمي قرآني للأطفال (5-6 سنوات) بجودة احترافية.

## ✨ المميزات

- 🎙️ **صوت الراوي**: Google AI Studio (Gemini 2.0 Flash TTS)
- 📖 **التلاوة القرآنية**: صوت حقيقي من everyayah.com (لا TTS)
- 🛡️ **حماية القرآن**: 5 طبقات ضد هلوسة النص
- 🎬 **جودة الفيديو**: H.264 CRF=16 (أعلى جودة)
- 🖊️ **السبتايتل**: عربي احترافي مع PIL + Arabic Reshaper
- 🔄 **الاستئناف الذكي**: من أي مرحلة عند الانقطاع
- 📊 **الحالة الحية**: Supabase لتتبع الحلقات
