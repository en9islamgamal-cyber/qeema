# QEEMA (قيمة) — بايب لاين تفسير القرآن للأطفال

أتمتة كاملة لإنتاج حلقات تفسير قصيرة (2–3 دقايق) للأطفال:
تلاوة حقيقية (الحصري المعلّم من everyayah) + شرح بالعامية المصرية (ElevenLabs) +
اسكتشات يدوية (Leonardo) + تجميع فيديو حقيقي (FFmpeg) + رفع على يوتيوب.

## بناء الحلقة
مقدمة (الصورة كاملة) ← تلاوة أولى ← شرح فكرة فكرة (زوم على كل ركن من شبكة 2×2)
← ختام ← تلاوة ثانية (مراجعة) ← الأوترو.

## خطوات التشغيل (مرة واحدة)
1. **قاعدة البيانات**: في Supabase > SQL Editor شغّل:
   - `sql/01_schema.sql`  (الجداول)
   - `sql/02_seed_curriculum.sql`  (الـ 38 حلقة)
2. **الأسرار**: حُط القيم في GitHub > Settings > Secrets (شوف `.env.example` للأسماء).
   - مهم: `SUPABASE_KEY` لازم يكون **service_role** (مش anon).
   - تأكّد إن `ELEVENLABS_VOICE_ID` هو صوتك بالظبط.
3. **الأصول**: `assets/logo.png` و `assets/outro.mp4` موجودين (بتوعك).
4. **التشغيل**: Actions > QEEMA Pipeline > Run workflow.
   - سيب `episode_id` فاضي = يشغّل التالية المجدولة.
   - أو حُط رقم (مثلاً `7`) = يشغّل الحلقة دي إجباريًا.

## محليًا
```
npm install
npx tsx server/run.ts 7      # حلقة معينة
npx tsx server/run.ts        # التالية المجدولة
```
(لازم ffmpeg + ffprobe + خط Noto Naskh Arabic مركّبين.)

## بنية الكود (server/)
| ملف | الدور |
|-----|-------|
| `config.ts` | كل الإعدادات والمفاتيح |
| `prompts.ts` | نظام الأوامر (هوية + ستايل + قواعد منع الهلوسة) |
| `reciter.ts` | تلاوة everyayah + atempo 1.12 |
| `llm.ts` | Gemini (تدوير 3 مفاتيح) -> EpisodePlan + العنوان |
| `voice.ts` | ElevenLabs (إزالة التشكيل) |
| `images.ts` | Leonardo (اسكتش + ثمبنايل) |
| `video.ts` | تجميع FFmpeg (شبكة + زوم + تعليقات + أوترو) |
| `youtube.ts` | الرفع |
| `orchestrator.ts` | يربط الكل + إعادة المحاولة |
| `run.ts` | نقطة الدخول |

## ⚠️ نقاط تتأكد منها في أول تشغيل (لسه ماتجرّبتش end-to-end هنا)
- **البسملة**: في السور غير الفاتحة، لو طلعت ناقصة من التلاوة، التعديل سطر واحد في `reciter.ts`.
- **التعليقات العربية المحروقة (ASS)**: تتأكد إن الخط بيظهر صح RTL (الخط مركّب في الـ workflow).
- **موديل Leonardo**: الـ modelId الافتراضي عام؛ غيّره لستايل أقرب لرسم الأطفال لو حبيت.
- **زمن الزوم**: قابل للضبط في `video.ts` (zoompan).
- الكود مكتوب ليفشل **بصوت عالٍ** عند أي خطأ — مفيش نجاح كاذب أو placeholder.
